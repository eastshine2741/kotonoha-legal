Kotonoha 계정 삭제 안내

최종 업데이트: 2026년 5월 28일

Kotonoha(코토노하)는 사용자가 앱 내에서 직접 계정과 학습 데이터를 삭제할 수 있도록 하고 있습니다. 이 페이지는 Google Play 데이터 안전성(Data Safety) 정책에 따라 삭제 절차와 처리 방식을 안내합니다.

1. 앱 내에서 삭제하는 방법

  1. Kotonoha 앱을 실행합니다.
  2. 홈 화면 우측 상단 또는 프로필 메뉴에서 설정을 엽니다.
  3. 설정 화면 가장 아래의 계정 삭제 항목을 누릅니다.
  4. 안내 다이얼로그를 확인한 뒤 계속을 누릅니다.
  5. 마지막 확인 화면에서 삭제를 입력하고 계정 삭제 버튼을 누릅니다.

2. 삭제 처리되는 데이터

계정 삭제 요청 시 아래 데이터가 처리됩니다.

항목처리 방식
계정 식별 정보 (이메일 주소, 표시 이름) 즉시 영구 삭제
Google 로그인 연결 정보 (Google 계정 고유 식별자) 즉시 식별 불가능한 형태로 변경되어 향후 영구 삭제 대상에 포함
사용자명(username) 즉시 식별 불가능한 형태로 변경되어 향후 영구 삭제 대상에 포함
저장한 단어, 플래시카드, 학습 이력, 덱, 일일 학습 통계, 사용자 설정 등 모든 학습 데이터 접근 불가능한 상태로 비활성화되며, 일정 보관 기간 이후 영구 삭제 대상에 포함

삭제 즉시 해당 계정으로는 로그인할 수 없으며, 모든 학습 데이터에 다시 접근할 수 없습니다.

3. 데이터 보관 및 영구 삭제 시점

계정과 식별 정보는 삭제 요청 즉시 처리되지만, 학습 데이터는 운영상의 이유로 일정 기간 보관된 후 영구 삭제될 수 있습니다. 운영자는 보관된 데이터에 일상적인 운영 목적으로 접근하지 않으며, 보관 기간이 종료되면 자동으로 영구 삭제 처리될 예정입니다.

법령에서 보관을 요구하는 경우 해당 법령이 정한 기간 동안만 별도로 보관됩니다 (자세한 내용은 개인정보처리방침을 확인해주세요).

4. 보존되지 않는 데이터

  • 익명화된 통계, 마케팅 목적의 별도 데이터를 보존하지 않습니다.
  • 백업 매체에 남는 사본은 백업 보존 주기가 지나면 자동으로 폐기됩니다.

5. 같은 Google 계정으로 다시 가입할 경우

계정을 삭제한 뒤 같은 Google 계정으로 다시 로그인하면 새 계정이 생성됩니다. 이전 계정의 학습 데이터는 복원되지 않으며, 사용자명도 다시 선택해야 합니다.

6. 삭제 요청을 위한 다른 방법

앱에 접근할 수 없는 상태이거나 앱 내 절차를 진행하기 어려운 경우, 아래 이메일로 가입에 사용한 Google 계정 주소를 적어 삭제를 요청해주세요. 본인 확인 후 동일한 절차로 처리해드립니다.
